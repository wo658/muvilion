# Muse가 축척과 바닥 외곽선을 정하고, 첫 인테리어를 자동 적용한다

현재 변경: [ADR-0013](0013-atomic-muse-operations.md)에 따라 모든 설계가 operation 단위로 즉시 커밋되므로 첫 자동 설계도 예외가 아니다. 자동 실행 조건과 1회 실행 규칙은 유지한다.

사용자 요청에 따라 도면 준비의 축척 확정을 사용자에서 Muse로 옮기고, 브랜드 자료가 있는 새 프로젝트는 처음 열 때 내부까지 꾸며진 상태로 완성한다. [ADR-0011](0011-nextjs-document-preparation.md)의 "축척은 미확정으로 둔다"와 [ADR-0004](0004-reviewed-design-proposals.md)의 "공간 변경은 사용자 Apply로만 반영"에 대한 예외다.

## 축척과 바닥 외곽선

- 벽 추적과 별도 Muse 호출을 병렬로 실행한다. 측정 호출은 인쇄된 축척 막대(없으면 판독 가능한 치수선)의 두 눈금 위치와 실제 길이, 그리고 주 행사 바닥의 실내 외곽선을 돌려준다.
- 비전 모델의 좌표는 몇 % 오차가 있다. 1차 추정 주변을 확대하고 좌표 격자를 그려 막대 몸통 범위를 두 번 다시 읽어 평균한다. 1차 추정과 25% 넘게 다른 판독은 버린다. Moscone West L3에서 1차 추정만은 −4%, 확대·격자 재판독 후 −0.5% 오차였다.
- 도면 크기 계산은 사용자의 두 점 보정과 같은 코드 규칙(원본 픽셀 거리 → 미터)으로 한다. 모델이 미터 값을 직접 정하지 않는다. 범위를 벗어나거나 너무 짧은 기준은 버린다.
- Muse가 정한 축척은 `scaleConfirmed: true`, `scaleSource: "muse"`, `scaleEvidence`로 저장하고 화면에 "Muse 측정"과 근거를 표시한다. 사용자가 다시 측정하면 `scaleSource: "user"`로 대체된다. 기존 문서의 출처 없는 확정은 사용자 확정으로 읽는다.
- 바닥 외곽선은 자기 교차가 없는 다각형만 받는다. 이미 검토된 외곽선이나 사용자 축척은 덮어쓰지 않는다.
- 측정 실패는 벽 읽기를 막지 않는다. 축척이 없으면 [design.md](../../web/design.md)의 필수 축척 단계가 사용자에게 열린다.

## 첫 인테리어 자동 적용

- 샘플 프로젝트 생성 시 선택된 브랜드 URL이나 참고 이미지가 있으면 `autoDesignPending`을 켠다. 업로드로 시작한 빈 프로젝트에는 생성 시 자료가 없으므로 켜지지 않는다.
- 활성 도면에 축척·바닥 외곽선이 있고 디자인이 비어 있으면 Studio가 바닥 전체 가구 배치 인테리어 설계를 한 번 실행하고 결과를 제안 단계 없이 적용한다. 시작할 때 플래그를 지워 새로고침·실패 뒤에 다시 실행하지 않는다.
- 설계 자체는 기존 Designer Muse 경로를 그대로 쓰므로 기하·동선·좌석 검사와 시각 자체 검토를 거친다. 적용은 일반 편집과 같은 되돌리기 기록에 남아 한 번에 빈 공간으로 돌아갈 수 있다. 이후 설계 요청은 계속 검토 후 Apply한다.

## 재검토 조건

축척 오차가 설계·견적에 실제 문제를 일으키거나, 자동 적용이 사용자의 의도와 자주 어긋나면 사용자 확인 단계로 되돌린다.
