# 초기 기획서는 세션 캡처 스냅샷으로 출력했다

초기 제작 흐름에서는 실제 3D 캡처와 당시 도면·참고 자료를 묶어 일회성 인쇄 문서를 만들었다. 영속 문서 편집 모델을 추가하기 전 캡처와 입력 버전이 섞이지 않도록 스냅샷을 고정하고, 별도 PDF 서버 대신 브라우저 인쇄를 사용했다. 캡처와 수동 입력 제목·설계 의도는 패널 세션에만 남았다.

이 기록은 `c1f172e`의 초기 구현을 설명하는 과거 결정이다. **현재 기획 문서의 저장 정책으로 사용하지 않는다.** `18ceb83`에서 [ADR-0007](0007-persistent-planning-artifacts.md)의 도면별 영속 문서로 대체되었다. 현재 코드를 위한 깨진 과거 파일 링크는 두지 않는다.

대체된 부분은 세션에만 남는 문서와 수동 문서 필드다. 실제 장면 캡처, 도면/참고 자료와의 기준 일치, 브라우저 PDF 인쇄는 새 설계에서도 유지된다. 남아 있는 스냅샷 헬퍼가 초기 세션 전용 UI의 존속을 뜻하지 않는다.
