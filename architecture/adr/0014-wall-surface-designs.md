# 벽면 디자인은 벽의 근거와 분리된 표면 디자인으로 저장한다

공간 디자인에는 기존 벽과 가벽의 마감·문구·그래픽이 포함된다. 원본 벽 선을 재작성하거나 벽과 겹치는 별도 설치물을 만들어 표현하면 근거가 변하거나 충돌 검사에 걸린다. `PlanDocument.wallSurfaces`를 선택적 디자인 컬렉션으로 추가하고 기존 벽 선 ID 또는 가벽 설치물 ID와 면 방향을 참조한다. 기존 문서는 이 컬렉션 없이 그대로 읽힌다.

표면은 호스트의 폭 안의 구간과 높이로 한정한 두께 없는 표현이다. 색상·카탈로그 재질·문구·스트라이프/프레임을 저장하며 임의 이미지·로고 복원·입체 부착물·시공 적합성은 포함하지 않는다. 물리적 가구 수나 바닥 충족률에는 넣지 않고 벽면 요구사항으로 별도 연결한다. 실제 두께를 가진 설치물은 기존 설치물 계약과 충돌 검사를 사용한다.

ADR-0013의 operation 경로로 추가·수정·삭제를 전달하고 undo·SQLite·내보내기에 포함한다. 호스트 삭제는 표면 삭제와 같은 묶음이어야 하며, 잘못된 참조나 호스트 높이 초과는 적용 전에 거부한다. 과거 자료의 벽 재분류 등으로 참조가 사라진 저장 문서는 읽되 떠 있는 마감을 렌더링하지 않는다. Crop은 기존 설치물과 함께 표면도 초기화한다. 원본 벽·축척·외곽선은 수정하지 않는다.
